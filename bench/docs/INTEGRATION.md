# Contract status and Arena handoff

## Packaged contract

The authoritative schema for this standalone release is [aeb-v0.1.json](../src/aeb/data/contracts/aeb-v0.1.json), with its byte-level digest in [lock.json](../src/aeb/data/contracts/lock.json). It is generated by [generate_assets.py](../scripts/generate_assets.py) and bundled into wheels. Import verifies the lock. Scenario, observation, action and event envelopes use JSON Schema 2020-12.

Status is `provisional-owned-contract`. No released Project 1 / execution-lab schema was provided or found in the user's repositories at implementation time. No upstream conformance or shared scoring authority is claimed. There is one packaged artifact, not two independently maintained copies in this repository.

When a real Lab release becomes available, review its license and semantics, import its immutable release artifact with provenance/digest, implement an explicit mapping, and add cross-repository conformance vectors. AEB utility and market scoring remain its own responsibility. Do not relabel the current schema as an upstream release or fabricate a compatible version number.

## Public Arena file

```bash
aeb export-arena \
  --trace runs/first/episodes/late-unknown-dev--seed-7/events.jsonl \
  --out runs/arena-replay.json
```

The file contains `schema_version=aeb-arena-replay-0.1`, `source=synthetic`, `authority=offline-benchmark`, a separate track label, `production_ranking_eligible=false`, allowlisted public events, and recomputed public metrics. It omits arbitrary extra event fields. The exporter never reads evaluator traces, full scenarios, model conversations or checkpoints.

This is an import artifact for an Arena-owned backend projector, not an implementation of Arena's `/api/*` contract. No Arena backend migration, API deployment or frontend integration is bundled or claimed. The Arena frontend must consume the backend's public projection and clear its previous game state on game-ID changes. It must not read evaluator files directly.

Display synthetic, testnet and real-chain provenance separately. Diagnostic duplicates are simulated counterfactual payments; they must not enter real payment statistics, real-provider reputation, official rankings, or production capacity claims. No part of this benchmark disables any real-wallet authorization guard.

## API-independent integration

The Python policy interface can be wrapped by a third-party agent harness by passing observations into the harness and returning the batch schema. Magentic Marketplace is a possible external host, but no tested adapter to its internal API is claimed. The benchmark does not require its database or service runtime.
